# Web Component: Botón de Descarga Rojo con Efecto Hover Here's a custom web component for a red download button with a hover effect that makes it larger: ```html Botón de Descarga Rojo

Ejemplo del botón:

``` ## Características del componente: 1. **Diseño visual**: - Color rojo (#e74c3c) con un tono más oscuro al hacer hover (#c0392b) - Incluye un icono de descarga SVG integrado - Texto "Descargar" por defecto 2. **Efecto hover**: - El botón se escala a 1.1 veces su tamaño original (transform: scale(1.1)) - Sombra más pronunciada - Transición suave de 0.3 segundos 3. **Funcionalidad**: - Emite un evento personalizado 'download-click' cuando se presiona - Permite cambiar el texto del botón mediante el atributo "text" o el método setButtonText() 4. **Uso**: ```html ``` Puedes personalizar aún más este componente añadiendo más atributos para controlar el color, tamaño, o cualquier otra propiedad visual.
